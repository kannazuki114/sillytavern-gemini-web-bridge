启动与连接说明
  1. 首次使用：在完整后端包内运行 start-gemini.bat，登录 Gemini。
  2. SillyTavern 可将完整后端包放入 plugins/gemini-web-bridge 并开启 enableServerPlugins。TauriTavern 或未启用服务端插件时，运行 start-bridge-gemini.bat，并保持服务窗口开启。
  3. 点击“检测连接与模型”，再点击“应用到 API 连接”；本机后端无需真实 API Key。

前端面板无法直接启动本机程序。浏览器 / 网页应用 / 桌面客户端的选择请在后端 config.json 中设置。

“读取酒馆后端”仅适用于已加载本项目服务端插件的 SillyTavern。普通连接检测不会发送对话或触发 Gemini 生成。
